## 项目概述

这是一个基于 **Vue 3 + TypeScript + PixiJS v8** 构建的现代化图形编辑器项目，采用组合式 API 和最新的前端技术栈。

### 项目特点

- ✅ **Vue 3.5+** - 最新的 Vue 3 组合式 API
- ✅ **TypeScript** - 完整的类型支持
- ✅ **Vite (Rolldown)** - 极速开发构建
- ✅ **Pinia 3.0** - 现代化状态管理
- ✅ **PixiJS v8** - 高性能 2D 渲染引擎
- ✅ **Ant Design Vue** - 企业级 UI 组件库
- ✅ **代码规范** - ESLint + Prettier + Stylelint
- ✅ **Git 规范** - Husky + Commitlint

### 核心模块说明

#### 1. Editor 核心层 (`src/editor/`)

完全独立于 Vue 的纯 TypeScript 编辑器内核，可被任何框架集成。

**职责：**
- 编辑器生命周期管理
- 画布对象管理
- 工具系统
- 命令系统（撤销/重做）
- 事件系统

#### 2. UI 组件层 (`src/components/`)

Vue 组件，负责界面展示和用户交互。

**分类：**
- `layout/` - 布局组件（头部、侧边栏、内容区、底部）
- `editor/` - 编辑器专用组件
- `common/` - 通用组件

#### 3. Hooks 层 (`src/hooks/`)

Composition API，封装编辑器功能。

**核心 Hooks：**
- `useEditor` - 编辑器实例管理
- `useImageUpload` - 图片上传处理
- `useCanvas` - 画布操作
- `useTool` - 工具切换
- `useHistory` - 历史记录

## 开发规范

### Git 提交规范

使用 [Conventional Commits](https://www.conventionalcommits.org/) 规范。

**格式：**
```
<type>(<scope>): <subject>

<body>
```

**Type 类型：**
- `feat`: 新功能
- `fix`: Bug 修复
- `docs`: 文档更新

- `refactor`: 代码重构
- `perf`: 性能优化

**示例：**
```bash

实现了图片上传到画布的完整流程，支持 PNG、JPG 等格式
```

## 迁移指南

### BaseCanvas 到 Editor 迁移

#### 1. 初始化方法

**旧代码：**
```typescript
const baseCanvas = new BaseCanvas()
await baseCanvas.init(container, {
  background: '#1099bb',
  resizeTo: container,
})
```

**新代码：**
```typescript
const editor = new Editor()
await editor.init({
  container,
  backgroundColor: 0x1099bb,
  resizeTo: container,
})
```

**变更点：**
- `background` → `backgroundColor`
- 颜色从字符串改为十六进制数字
- 配置对象包含 `container`

#### 2. 图片加载方法

**旧代码：**
```typescript
await baseCanvas.setRenderImage(imageUrl)
```

**新代码：**
```typescript
await editor.loadImage(imageUrl)
```

#### 3. 使用 Hook（推荐）

```vue
<script setup lang="ts">
import { useEditor } from '@/hooks'

const { init, loadImage, resize } = useEditor({
  backgroundColor: 0x1099bb,
})

onMounted(async () => {
  await init(container.value)
  await loadImage(imageUrl)
})
</script>
```

## 最佳实践

### 1. 使用 shallowRef 存储 Pixi 对象

```typescript
// ✅ 正确
const editor = shallowRef<Editor | null>(null)

// ❌ 错误：会导致性能问题
const editor = ref<Editor | null>(null)
```

### 2. 使用 storeToRefs 解构 Store

```typescript
// ✅ 正确：保持响应性
const { currentTab } = storeToRefs(globalStore)

// ❌ 错误：失去响应性
const { currentTab } = globalStore
```

### 3. 使用 $patch 批量更新 Store

```typescript
// ✅ 推荐
globalStore.$patch({
  currentTab: 'add',
  isEmpty: false,
})

// ⚠️ 可用但不推荐
globalStore.currentTab = 'add'
globalStore.isEmpty = false
```

### 4. 图片加载使用 Data URL

```typescript
// ✅ 推荐：使用 FileReader 转换为 Data URL
const reader = new FileReader()
reader.onload = e => {
  const dataUrl = e.target?.result as string
  await editor.loadImage(dataUrl)
}
reader.readAsDataURL(file)
```

## 常见问题

### Q1: 如何调试图片加载问题？

查看控制台日志，按照日志顺序排查：
1. 文件选择是否触发
2. FileReader 是否成功读取
3. Store 是否正确更新
4. watch 是否触发
5. Editor 是否初始化
6. 图片是否加载成功

### Q2: 如何添加新的路由？

1. 在 `src/constants/enum/route.ts` 添加枚举
2. 在 `src/router/index.ts` 添加路由配置
3. 创建对应的 View 组件

### Q3: 如何添加新的 Store？

1. 在 `src/constants/enum/store.ts` 添加枚举
2. 在 `src/store/modules/` 创建新文件
3. 在 `src/store/index.ts` 导出

### Q4: PixiJS v8 有什么变化？

- 初始化需要 `await app.init()`
- 使用新的 Graphics API：`graphics.rect().fill()`
- 使用 `eventMode` 代替 `interactive`
