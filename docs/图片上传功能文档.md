## 功能概述

用户可以在缺省页上传图片，图片会自动加载并渲染到 PixiJS 画布上。

### 核心特性

- ✅ 支持多种图片格式（PNG、JPG、GIF、WEBP）
- ✅ 文件类型和大小验证
- ✅ 可选图片压缩
- ✅ 实时进度显示
- ✅ 完整错误处理
- ✅ TypeScript 类型支持

---

## 技术方案

### 完整数据流

```
用户选择图片
    ↓
FileReader 读取文件
    ↓
转换为 Base64 Data URL
    ↓
useImageUpload Hook 处理
    ↓
Store 状态更新
    ↓
MainContent watch 监听
    ↓
Editor.loadImage() 加载
    ↓
PixiJS 渲染到画布
```

### 为什么使用 Data URL（Base64）？

| 方案 | 优点 | 缺点 | 推荐度 |
|------|------|------|--------|
| Blob URL | 性能好 | Pixi.js 不兼容 | ❌ |
| **Data URL** | **完全兼容** | 体积+33% | ✅ 推荐 |
| File 直接传递 | 无转换 | 难以跨组件 | ⚠️ |

**选择 Data URL 的原因：**
1. Pixi.js 完全兼容
2. 跨浏览器一致
3. 无跨域问题
4. 可持久化存储

## useImageUpload Hook

### API 接口

```typescript
const {
  // 状态
  loading: Ref<boolean>        // 是否加载中
  progress: Ref<number>         // 进度 (0-100)
  error: Ref<string | null>     // 错误信息
  imageInfo: Ref<ImageInfo | null>  // 图片信息
  
  // 方法
  handleFile: (file: File) => Promise<ImageInfo>  // 处理文件
  validateFile: (file: File) => ValidationResult   // 验证文件
  reset: () => void  // 重置状态
} = useImageUpload(options)
```

### 配置选项

```typescript
interface ImageUploadOptions {
  maxSize?: number      // 最大文件大小，默认 10MB

  maxWidth?: number     // 最大宽度，默认 2048

}
```

interface ImageInfo {

## 问题排查

### 常见问题

#### 问题 1：图片无法加载

**症状：** `Cannot read properties of undefined (reading 'width')`

**原因：** `Texture.from(dataUrl)` 返回 undefined

**解决：** 使用 Image 对象加载

```typescript
// ❌ 错误
const texture = await Texture.from(dataUrl)

// ✅ 正确
const img = new Image()
img.onload = () => {
  const texture = Texture.from(img)
}
img.src = dataUrl
```

#### 问题 2：watch 不触发

**症状：** 上传图片后没有渲染

**原因：** storeToRefs 使用不当

**解决：**

```typescript
// ✅ 正确
const { uploadedImageUrl } = storeToRefs(globalStore)
watch(uploadedImageUrl, callback)

// ❌ 错误
watch(() => globalStore.uploadedImageUrl, callback)
```

#### 问题 3：Data URL 格式错误

**验证方法：**

```typescript
const isValidDataURL = (url: string) => {
  return /^data:image\/(png|jpg|jpeg|gif|webp);base64,/.test(url)
}
```

### 完整示例（EmptyView）

```vue
<script setup lang="ts">
import { useImageUpload } from '@/hooks'
import { useFileDialog } from '@vueuse/core'
import { useGlobalStore } from '@/store/modules/global'
import { message } from 'ant-design-vue'

const globalStore = useGlobalStore()

// 使用 Hook
const { handleFile, loading, error, imageInfo } = useImageUpload({
  maxSize: 10 * 1024 * 1024,  // 10MB
  compress: false,             // 不压缩，保持原图质量
})

// 文件选择
const { open, onChange } = useFileDialog({
  multiple: false,
  accept: 'image/*',
})

// 处理上传
onChange(async files => {
  if (files && files[0]) {
    try {
      const info = await handleFile(files[0])
      
      // 存储到 Store
      globalStore.setUploadedImageUrl(info.dataUrl)
      globalStore.setIsEmpty(false)
      
      message.success(`上传成功：${info.name}`)
    } catch (err) {
      message.error(err.message)
    }
  }
})
</script>

<template>
  <div class="empty-view">
    <div class="empty-view-content" @click="open">
      <!-- 图标 -->
      <add-picture :size="80" :class="{ loading }" />
      
      <!-- 文本 -->
      <div v-if="!loading">选择添加文件或拖拽到此处</div>
      <div v-else>正在加载图片...</div>
      
      <!-- 图片信息 -->
      <div v-if="imageInfo">
        {{ imageInfo.name }} ({{ (imageInfo.size / 1024).toFixed(2) }} KB)
      </div>
      
      <!-- 错误提示 -->
      <div v-if="error" class="error">{{ error }}</div>
    </div>
  </div>
</template>
```

### MainContent 监听渲染

```vue
<script setup lang="ts">
import { watch } from 'vue'
import { useEditor } from '@/hooks'
import { useGlobalStore } from '@/store/modules/global'
import { storeToRefs } from 'pinia'

const globalStore = useGlobalStore()
const { uploadedImageUrl } = storeToRefs(globalStore)

const { init, loadImage, initialized } = useEditor({
  backgroundColor: 0x1099bb,
})

// 监听图片上传
watch(uploadedImageUrl, async newUrl => {
  if (newUrl) {
    // 确保编辑器已初始化
    if (!initialized.value) {
      await waitForInit()
    }
    
    // 加载图片
    await loadImage(newUrl)
  }
}, { immediate: true })
</script>
```

### Editor 加载图片

```typescript
// Editor.ts
async loadImage(imageUrl: string): Promise<void> {
  try {
    let texture: Texture

    if (imageUrl.startsWith('data:')) {
      // Data URL：使用 Image 对象加载
      texture = await new Promise<Texture>((resolve, reject) => {
        const img = new Image()
        img.onload = () => {
          const tex = Texture.from(img)
          resolve(tex)
        }
        img.onerror = () => reject(new Error('加载失败'))
        img.src = imageUrl
      })
    } else {
      // HTTP URL：使用 Assets.load
      texture = await Assets.load(imageUrl)
    }

    // 创建精灵并渲染
    this.currentSprite = new Sprite(texture)
    this.fitSpriteToScreen()
    this.application.pixiApp.stage.addChild(this.currentSprite)
  } catch (error) {
    console.error('图片加载失败:', error)
    throw error
  }
}
```

## 总结

### 核心技术

- ✅ **FileReader + Data URL**：最可靠的浏览器文件处理方案
- ✅ **Image + Texture.from()**：Pixi.js 加载 Data URL 的正确方式
- ✅ **响应式状态管理**：Vue 3 + Pinia 完美配合
- ✅ **Hook 封装**：逻辑复用，代码简洁

### 关键要点

1. **必须使用 Data URL**：Blob URL 在 Pixi.js 中不兼容
2. **正确的加载方式**：先用 Image 加载，再创建 Texture
3. **watch 监听**：使用 storeToRefs 保持响应性
4. **完整的错误处理**：验证、读取、加载各环节

### 优势

- 🎯 **简单易用**：3 行代码完成上传
- 🛡️ **类型安全**：完整 TypeScript 支持
- 🎨 **可扩展**：易于添加新功能
