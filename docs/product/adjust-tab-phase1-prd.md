## 1. 文档说明

本文是【调整】Tab **一期**的产品需求说明，供产品评审、验收与研发对齐使用。

- **写什么：** 用户要解决什么问题、交付哪些能力、交互与边界、验收标准。
- **不写什么：** 具体类名、文件路径、实现步骤（见 OpenSpec `design.md` / `tasks.md`）。
- **与开发 Prompt 的关系：** 本文由《【调整】Tab 功能模块一期开发需求 Prompt》提炼为正式 PRD；范围与 OpenSpec proposal 保持一致。

## 2. 背景与目标

### 2.1 背景

编辑器已具备：工程底座、四区壳层、Pixi 画布、主图导入与视口平移缩放、【调整】Tab 占位（目前仅平移可用）。

用户导入主图后，还无法在【调整】工作区完成「裁切构图 / 旋转翻转 / 改显示尺寸」等基础调整，与参考产品（美图类）的调整能力存在缺口。

### 2.2 一期目标

在**不引入画布自由变换系统**的前提下，让用户对**当前唯一主图**完成：

1. **按比例裁剪**（非破坏）
2. **旋转与翻转**（含自定义角度）
3. **修改显示尺寸**（锁比例 + 多单位）

### 2.3 成功标准（产品视角）

- 用户能在【调整】里找到并使用上述三个模块，且交互符合「手风琴 + 预览 + 提交保留」心智。
- 调整结果正确反映在画布主图上，可撤销 / 重做。
- 画布上**不出现**选中框、缩放手柄、旋转手柄；视口平移仍可用。
- 不破坏现有导入、视口、壳层能力。

## 3. 用户与场景

### 3.1 目标用户

本地修图 / 出图用户：已打开编辑器并导入一张主图，需要快速改构图、朝向或显示尺寸。

### 3.2 核心场景

| ID | 场景 | 期望结果 |
|---|---|---|
| S1 | 把横图裁成 1:1 头像构图 | 画布上只保留裁切区域，原图资源仍可再裁 |
| S2 | 照片方向不对，右旋 90° 再水平翻转 | 朝向正确；可逐步撤销 |
| S3 | 按厘米输入宽度，并保持比例 | 高度联动；切回像素后数值一致 |
| S4 | 试了一下裁剪后点取消 | 主图回到进入裁剪前的状态 |
| S5 | 改完尺寸后收起面板再开 | 效果仍在；可继续微调 |

## 4. 范围

### 4.1 本期做（In Scope）

| 模块 | 能力 |
|---|---|
| 调整面板结构 | 三个一级入口：裁剪、旋转/矫正、改尺寸/比例；默认收起；互斥展开 |
| 裁剪 | 仅**按比例裁剪**（四角锁比例）；边中点自由拉一边；预设比例；画布内裁剪框 + 遮罩；拖动时井字辅助线；应用后自适应居中；再进裁剪时框铺满当前可见图；非破坏 |
| 旋转 | 左旋 90°、右旋 90°、左右翻转、上下翻转、自定义角度；旋转/翻转后实时自适应画布并居中 |
| 改尺寸 | 宽 / 高输入、锁定比例（默认开）、单位 px / in / cm；改主图显示尺寸 |
| 历史 | 本期三项操作可 Undo / Redo（顶栏撤销 / 重做对本栈生效） |
| 平移 | 现有视口平移保留 |

### 4.2 本期不做（Out of Scope）

| 类别 | 明确不做 |
|---|---|
| 画布变换 | 主图自由选择、拖动、缩放、包围盒、Resize / Rotation Handle（feat-008） |
| 裁剪增强 | 按尺寸裁剪、按形状裁剪、圆形/多边形、蒙版裁剪、自定义尺寸预设列表 |
| 旋转增强 | 矫正子 Tab、全图显示、自动裁剪、滑条矫正（若参考图有，一期可不做） |
| 改尺寸增强 | 拉伸 / AI 扩图 / 纯色背景、画质修复、改**画布/文档**尺寸 |
| 对象模型 | 多图层、多图、多选、批量处理 |
| 其他 | AI 编辑、高级滤镜、复杂重采样 |

> 若实现中发现 Out of Scope 项是硬依赖，须先说明依赖并评审是否补最小实现，**禁止擅自扩 scope**。

## 5. 信息架构与整体交互

### 5.1 结构

```text
调整
├── 裁剪
├── 旋转/矫正
└── 改尺寸/比例
```

（界面文案可与设计稿对齐：如「旋转/矫正」「改尺寸/比例」。）

### 5.2 手风琴规则

| 规则 | 说明 |
|---|---|
| 默认 | 三个入口全部收起 |
| 展开 | 点击收起项 → 展开该模块界面 |
| 收起 | 再次点击已展开项 → 收起 |
| 互斥 | 同时最多展开一个；展开新模块时自动收起旧模块 |
| 无主图 | 允许打开入口，但操作不改变文档 |

### 5.3 统一交互原则

```text
点击一级入口 → 展开面板 → 改参数 / 操作
        → 画布实时预览
        → 收起 / 切换模块（或显式应用）
        → 已生效效果保留在主图
```

| 概念 | 含义 |
|---|---|
| UI 参数状态 | 当前面板上的比例、角度输入、单位、锁比例等 |
| 主图实际状态 | 文档中的尺寸、旋转、翻转、裁剪结果 |
| 要求 | 二者分离；真源为文档模型，画布只渲染 |

### 5.5 模块独立：以画布当前图为基准

三个一级功能彼此独立。**每次展开**某个模块时，操作对象都是**此刻画布上已经生效的那张图**，而不是最初导入的原图。

| 规则 | 说明 |
|---|---|
| 基准图 | 展开裁剪 / 旋转 / 改尺寸时，都以当前可见主图为准（含已应用的裁剪、旋转、翻转、显示尺寸） |
| 裁剪 → 旋转 | 先裁再展开旋转：绕**裁切后新图的中心**旋转，而不是绕原图中心 |
| 旋转 → 裁剪 | 先转再展开裁剪：裁剪框落在旋转后的可见图上 |
| 旋转中心 | 始终是画布上当前可见图片的中心 |
| 适配 | 旋转 / 翻转后（以及展开裁剪、旋转时）视口按当前可见图自适应并居中 |

```text
画布当前可见图
    ├── 展开裁剪 → 框铺满这张图，再裁切
    ├── 展开旋转 → 绕这张图的中心旋转，并适配画布
    └── 展开改尺寸 → 改这张图的显示宽高
```

### 5.4 提交与取消（产品约定）

| 行为 | 产品期望 |
|---|---|
| 在模块内产生过有效操作后，收起或切换到其他模块 | **保留**已生效预览（提交到主图） |
| 打开模块后未改动就收起 | 主图不变 |
| 裁剪显式「取消」 | 恢复进入该次裁剪会话前的状态 |
| 裁剪显式「应用」或等价提交 | 写入裁剪结果并可撤销 |
| 仅收起 UI ≠ 静默破坏原图数据 | 非破坏裁剪；取消不得损坏原始资源 |

## 6. 功能需求

### 6.1 裁剪

#### 6.1.1 一期范围

- **做：** 按比例裁剪  
- **不做：** 按尺寸、按形状、自由无约束裁剪、形状蒙版等  

#### 6.1.2 预设比例

| 选项 |
|---|
| 原比例 |
| 1:1 |
| 4:3 |
| 3:4 |
| 16:9 |
| 9:16 |
| 3:2 |
| 2:3 |

#### 6.1.3 交互与画布表现

用户路径：`调整 → 裁剪`。

展开后：

- 面板展示比例选项（及应用 / 取消等操作，样式跟现有壳层）。
- 画布进入裁剪态：
  - 显示裁剪框与裁剪区域
  - **框外变暗遮罩只覆盖中央画布 host，不得溢出到左侧面板、顶栏或整页**
  - 框保持所选比例
  - 可拖动框位置
  - 四角控制点：同时调整相邻两边，并保持所选比例
  - **上下左右边中点：只改变被拖动的那条边，对边不动；不改变另一维（拖上中点只改高度）。中点样式为矩形方块**
  - **井字形（三分线）仅在拖动框或控制点时显示，指针松开后隐藏**
  - 框不得超出主图
  - 实时预览最终裁切区域
  - **点击「应用」后，裁切结果自适应画布可见区域并居中**

#### 6.1.4 生效策略

| 阶段 | 行为 |
|---|---|
| 进入 | 记录进入前裁剪快照；创建临时裁剪状态 |
| 编辑中 | 实时预览 |
| 应用 / 有改动后收起 | 提交裁剪结果，进入历史；视口适配裁切后的主图并居中 |
| 取消 | 恢复快照，不产生历史 |
| 再次进入 | 裁剪框覆盖**当前可见主图**（若已裁过，即上次裁切后的新图）；框不得超出这张可见图；原图像素仍保留，确认后替换文档中的裁剪结果 |

#### 6.1.5 产品约束

- 裁剪为**非破坏**：不重编码 / 不丢弃原图资源。
- 无主图时操作无效。

---

### 6.2 旋转 / 翻转

#### 6.2.1 能力列表

| 操作 | 产品行为 |
|---|---|
| 左旋 90° | 逆时针 90°，立即生效并记一条历史 |
| 右旋 90° | 顺时针 90°，立即生效并记一条历史 |
| 左右翻转 | 水平镜像；**不改**已存储的旋转角 |
| 上下翻转 | 垂直镜像；**不改**已存储的旋转角 |
| 自定义角度 | 输入角度（可正可负、可超 360°），归一化到 0°～360° 后生效 |

#### 6.2.2 角度规则

- 内部角度归一化到 **0°～360°**（例：450° → 90°）。
- 非法输入（空、字母、特殊字符、NaN、Infinity）**拒绝**，保留上一次有效角度。
- 连续多次旋转 / 翻转应可逐步撤销。

#### 6.2.3 生效策略

| 操作类型 | 提交时机 |
|---|---|
| 90°、翻转 | 点击即生效 + 入历史；**画布立即按旋转后包围盒适配并居中** |
| 自定义角度 | 合法值可预览并同样实时适配画布；确认时机为失焦 / Enter / 收起模块 |

#### 6.2.4 与裁剪的衔接

收起旋转面板后进入裁剪时，必须按**当前旋转 / 翻转后的主图**重新计算裁剪框在画布上的位置与尺寸，使框仍落在可见主图上，而不是沿用旋转前的屏幕坐标。

先裁剪再进入旋转时，旋转对象是**裁切后的新图**，旋转中心是该新图在画布上的中心，并自适应画布。

---

### 6.3 修改尺寸

#### 6.3.1 界面要素

| 控件 | 说明 |
|---|---|
| 宽度 | 可编辑 |
| 高度 | 可编辑 |
| 锁定比例 | 默认**开启**；解锁后宽高独立 |
| 单位 | 像素 (px) / 英寸 (in) / 厘米 (cm) |

#### 6.3.2 锁定比例

进入模块时记录当前主图宽高比：

- 改宽 → 高 = 宽 ÷ 比例  
- 改高 → 宽 = 高 × 比例  
- 解锁后宽、高独立修改  

#### 6.3.3 单位

| 规则 | 说明 |
|---|---|
| 内部真源 | 像素 (px) |
| 切换单位 | **仅改变显示**，不改变实际像素尺寸 |
| DPI | 由文档级配置统一提供（产品约定默认 96），禁止各处写死不同值 |

换算关系：

```text
px = inch × dpi
inch = px / dpi
cm = inch × 2.54
inch = cm / 2.54
```

#### 6.3.4 作用对象

> 改的是**主图显示尺寸**，不是画布 / 文档 / host 尺寸。  
> 「画布尺寸」若需要，单独立项。

#### 6.3.5 生效与历史

| 规则 | 说明 |
|---|---|
| 输入过程 | 合法值实时预览 |
| 历史 | 不得按每个按键入栈；在 blur / Enter / 收起模块时若有改动，提交**一条**改尺寸历史 |
| 非法值 | 0、负数、非数字、非有限值、超上限等拒绝，保持原值 |

## 7. 跨模块约定

### 7.1 作用对象

三个模块均只作用于**当前主图**（一期仍为一张主图）。

### 7.2 状态真源（产品级）

- 主图状态统一由编辑器文档模型管理。
- 禁止三个面板各自维护一套互不同步的「图片真源」。
- 画布渲染层不得成为业务真源。

### 7.3 历史（Undo / Redo）

至少覆盖：

| 命令类型 | 说明 |
|---|---|
| 裁剪提交 | 一次会话确认 = 一条 |
| 旋转 90° | 每次点击 = 一条 |
| 翻转 | 每次点击 = 一条 |
| 自定义角度 | 一次确认 = 一条 |
| 改尺寸 | 一次确认 = 一条 |

要求：支持逐步撤销 / 重做；未提交的裁剪会话与改尺寸输入过程不入栈。

> 完整编辑器历史（导入替换、滤镜、文字等）不在本 PRD 范围；本期为调整能力提供最小可撤销栈即可。

## 8. 异常与边界（产品）

### 8.1 裁剪

- 所选比例大于 / 小于原图比例时，框仍须落在图内且保持比例。
- 极小裁剪区域有下限，避免不可用框。
- 框不得超出图片。
- 取消、重复进入裁剪行为符合 §6.1.4。

### 8.2 旋转

- 负角、超 360°、连续旋转、旋转 + 翻转组合均可预期工作。

### 8.3 改尺寸

- 0 / 负数 / 非数字 / 超大尺寸拒绝。
- 锁比例下切换单位不改变实际像素。
- 单位切换的显示精度可接受舍入，但切回 px 不得漂移出约定误差。
- 快速连续输入只产生一条确认历史。

## 9. 验收标准

### 9.1 面板结构

- [ ] 【调整】下可见裁剪、旋转/矫正、改尺寸/比例三个入口  
- [ ] 默认全部收起  
- [ ] 同时只展开一个；切换会收起前一个  
- [ ] **展开任一模块都以画布当前可见图为基准**  
- [ ] 平移仍可用；画布无选中变换手柄  
- [ ] 切换左侧其它 Tab 不重挂画布  

### 9.2 裁剪

- [ ] 可展开裁剪并选择预设比例  
- [ ] 画布有裁剪框；框外遮罩只在画布 host 内，不盖住整页  
- [ ] 框保持比例（四角）；可拖动；**上下左右边中点为矩形**，只改对应边，不出台  
- [ ] 拖动过程显示井字三分线，松开后隐藏  
- [ ] 可应用 / 可取消，结果正确；**应用后主图自适应画布并居中**  
- [ ] **再次进入裁剪时，框铺满当前可见的裁切结果**；Undo / Redo 正常  

### 9.3 旋转

- [ ] 左旋 / 右旋 90° 正常，且**实时自适应画布并居中**  
- [ ] 左右 / 上下翻转正常，且不改存储旋转角的产品语义；翻转后同样适配画布  
- [ ] 自定义角度与非法输入处理正常；预览过程也适配画布  
- [ ] 收起旋转后再进裁剪，裁剪框位置按旋转后主图重算  
- [ ] **先裁再旋转：绕裁切后新图中心转，并适配画布**  
- [ ] 连续操作与 Undo / Redo 正常  

### 9.4 修改尺寸

- [ ] 宽高可改；锁定 / 解锁比例正常  
- [ ] px / in / cm 正常；切换单位不改变实际尺寸  
- [ ] 非法输入正确处理；host / 画布尺寸不变  
- [ ] 快速输入只提交一条历史；Undo / Redo 正常  

### 9.5 无主图

- [ ] 无导入图时操作不产生主图、不污染文档
