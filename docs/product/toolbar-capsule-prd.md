## 1. 文档说明

本文描述顶栏 **布局重构**、**图标化**、**抓手公共化**、**对比原图** 的产品行为与验收标准。

- **写什么：** 信息架构、交互状态、禁用规则、对比语义、非目标。
- **不写什么：** 类名、文件路径、实现步骤（见 OpenSpec `design.md` / `tasks.md`）。
- **与 ui-spec 的关系：** 视觉 token、IconPark、Tooltip 规则以 [`ui-spec.md`](./ui-spec.md) 为准；本文只增补顶栏结构与行为。

---

## 2. 背景与目标

### 2.1 背景

当前顶栏为文字按钮三分区（打开 / 历史+撤销重做 / 适配+保存），【调整】面板内仍有「平移」按钮。与 [`ui-spec.md`](./ui-spec.md) 的图标化方向不一致；视口公共能力（平移、对比）分散在工作区与顶栏之间。

### 2.2 目标

1. **顶栏重构：** 左「品牌 + 导入」、中「胶囊工具条」、右「导出」；仅导入/导出留在胶囊外。
2. **图标化：** 胶囊内与导入/导出均为 IconPark outline + Tooltip；去掉文字按钮与「历史」占位。
3. **抓手公共化：** 从【调整】面板移除平移；顶栏胶囊提供 **抓手**（粘滞开关，Tooltip 文案「抓手」），与空格暂切、中键平移并存。
4. **对比原图：** 按住显示导入位图预览；不写文档、不进撤销栈。

### 2.3 成功标准

- 顶栏布局符合 §5 结构；hover 见 Tooltip，无文字按钮（品牌字除外）。
- 【调整】面板仅保留裁剪 / 旋转 / 改尺寸手风琴，**无平移入口**。
- 有主图时按住「对比原图」或 `\` 可预览导入位图；松手恢复；视口平移缩放不重置。
- 互斥与禁用表（§7）在手工验收中成立。

## 3. 用户与场景

| ID | 场景 | 期望 |
|---|---|---|
| T1 | 导入一张图后放大查看细节 | 开「抓手」或按住空格拖动画布 |
| T2 | 裁剪后想看裁掉了多少 | 按住「对比原图」，同一视口位置看到完整导入图 |
| T3 | 旋转后对比方向 | 按住对比，图回到 0° 自然像素，中心仍在当前可见图中心 |
| T4 | 在改尺寸输入框里编辑 | 按 `\` 不触发对比 |
| T5 | 再次导入换图 | 新图立刻替换；对比 baseline 更新；调整 undo 栈清空 |
| T6 | 裁剪会话中需要平移 | 关抓手或用空格/中键平移；按住对比时裁剪框隐藏 |

## 5. 信息架构

### 5.1 顶栏结构

```text
┌─────────────────────────────────────────────────────────────────┐
│ [编辑器] [导入]     ╭ 抓手 | 撤销·重做 | 对比原图 | 适配 ╮   [导出] │
└─────────────────────────────────────────────────────────────────┘
     左区                    中区 · 胶囊                    右区
```

- **左区：** 品牌文案「编辑器」+ 导入图标按钮。
- **中区：** 单颗胶囊（白底、`--chrome-border`、高度约 32px、大圆角约 16px），顶栏内 inline，不浮在画布上。
- **右区：** 导出图标（`type="primary"` 强调色）；本轮 **disabled**，仅换皮占位。

### 5.2 胶囊内分组

| 组 | 控件 | 组间分隔 |
|---|---|---|
| 视口 | 抓手 | 其后竖线 `\|` |
| 历史 | 撤销、重做 | 组内间距 8px；组后竖线 |
| 预览 | 对比原图 | 组后竖线 |
| 视口 | 适配 | — |

顺序固定：**抓手 | 撤销 · 重做 | 对比原图 | 适配**。

### 5.3 【调整】面板

```text
调整
├── 裁剪
├── 旋转/矫正
└── 改尺寸/比例
```

**不再包含**「平移 / 抓手」入口。

## 6. 控件文案与图标

| 位置 | Tooltip | IconPark（outline, 16px） | 交互 |
|---|---|---|---|
| 左 | 导入 | `FolderOpen` | 点击打开文件选择 |
| 胶囊 | 抓手 · `空格` | `Five` | 粘滞开关；选中强调色；空格为暂切 |
| 胶囊 | 撤销 · `Ctrl+Z` | `Undo` | 点击（快捷键接线见 feat-014/018） |
| 胶囊 | 重做 · `Ctrl+Y` | `Redo` | 点击（快捷键接线见 feat-014/018） |
| 胶囊 | 对比原图 · `\` | `Contrast` | **按住**显示原图；按住强调色 |
| 胶囊 | 适配 | `FullScreen` | 点击 fitView |
| 右 | 导出 | `Save` | disabled 占位 |

禁用态图标须明显变淡：按钮字色 / IconPark 继承 `--chrome-text-disabled`，不得 `color: inherit` 盖掉禁用色。

图标语义不足时按 `ui-spec` 附录替换，仍只用 IconPark outline。

每个图标按钮须提供 `aria-label`，与 Tooltip 一致。

## 7. 状态与互斥

### 7.1 禁用矩阵

| 状态 | 导入 | 抓手 | 撤销 | 重做 | 对比原图 | 适配 | 导出 |
|---|---|---|---|---|---|---|---|
| 无主图 | ✓ | ✗ | ✗ | ✗ | ✗ | ✗ | ✗ |
| 有主图 | ✓ | ✓ | 栈非空 | 栈非空 | ✓ | ✓ | ✗（占位） |

✓ = 可用；✗ = disabled。

### 7.2 行为规则

| 规则 | 说明 |
|---|---|
| 抓手默认 | 关闭；点击切换；选中时 `activeTool === 'pan'` |
| 空格 | 暂切平移，**不改变**抓手开关 |
| 中键 | 始终可平移视口 |
| 裁剪 / 旋转 / 改尺寸会话 | 各面板逻辑不变；**无**面板内平移按钮 |
| 抓手开 + 裁剪 | 左键拖画布平移；拖裁剪框需关抓手或空格暂切后操作 |
| 按住对比 | 顶栏其它点击不响应；**滚轮缩放、空格/中键平移仍可用** |
| 对比期间 | 隐藏 DOM 裁剪 overlay；不显示裁剪框/井字格 |
| 对比结束 | overlay 按裁剪会话原样恢复 |
| 焦点在 Input | `\` 不触发对比 |
| 换图 | 静默替换；`commandStack` 清空；`isComparingOriginal = false` |
| 空 host 点击 | 抓手关时仍可打开文件；抓手开时与现网一致不打开 picker |

## 8. 对比原图

### 8.1 语义

- **原图** = 当前主图对应的 **导入位图**（同一 `objectUrl` + `naturalWidth/Height`）。
- **不是** undo 历史上某一步，**不是**第二图层。

### 8.2 显示规则（按住期间）

| 项 | 行为 |
|---|---|
| 视口 | **不变**（`viewport` 不重算） |
| 世界锚点 | 当前 **可见图中心**（`transform.x/y`） |
| 去掉 | `crop`、旋转、翻转、改尺寸带来的 scale |
| 纹理 | 整张 natural 尺寸；anchor 0.5；无 mask |
| 文档 | **不修改** `layers[]` |
| 撤销 | **不产生** 命令 |

### 8.3 触发与结束

| 入口 | 开始 | 结束 |
|---|---|---|
| 胶囊「对比原图」 | `pointerdown` / `mousedown` | `pointerup` / `mouseup` / 指针离开窗口 |
| 键盘 `\` | `keydown`（无 Input 焦点） | `keyup` |

### 8.4 对齐说明（产品向）

用户已裁剪/旋转/改尺寸后按住对比，会在 **同一视口、同一屏幕中心点** 看到 **完整导入图**（可能更大、方向为 0°）。这是预期行为，用于查看「相对原图改了什么」，不是 bug。

## 10. 验收标准

### 10.1 布局与图标

- [ ] 顶栏左中右结构符合 §5.1；胶囊分组与竖线符合 §5.2
- [ ] 胶囊内无文字按钮；导入/导出为图标；Tooltip 文案符合 §6
- [ ] 导出仍为 disabled 主色按钮
- [ ] 【调整】面板无平移/抓手按钮

### 10.2 抓手

- [ ] 默认关；点击开/关；选中强调色
- [ ] 开时左键拖画布平移；空格暂切不改变开关；中键可平移
- [ ] 无主图时抓手 disabled

### 10.3 对比原图

- [ ] 有主图时按住按钮显示导入图；松手恢复
- [ ] 按住 `\` 同上；Input 聚焦时不触发
- [ ] 对比期间视口可滚轮缩放、空格/中键平移
- [ ] 对比期间裁剪 overlay 不可见；松手后恢复
- [ ] 裁剪/旋转/改尺寸后对比，中心对齐 §8.2，视口不跳

### 10.4 换图与栈

- [ ] 再次导入静默替换；undo 栈清空；对比状态复位

### 10.5 回归

- [ ] 撤销/重做仍只作用于调整命令
- [ ] 切左 Tab 不重挂 canvas
- [ ] `./init.sh` 通过

## 11. 风险与开放项

| 风险 | 缓解 |
|---|---|
| 裁剪中抓手与框抢手势 | PRD 明确关抓手或空格；验收 T6 |
| 对比时图突然变大 | §8.4 产品说明 + 首次使用 Tooltip 已足够 |
| 换图未清栈（现网缺口） | 本期显式要求 `addImageLayer` 清栈 |

开放项（本期不做）：导出接线、历史面板、H / Ctrl+0 快捷键。
