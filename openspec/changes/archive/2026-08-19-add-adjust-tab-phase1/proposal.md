## Why

左侧【调整】工作区目前只有平移和占位按钮，用户无法对已导入的主图做裁剪、旋转或改尺寸。产品一期要把这三个模块做成可展开的功能入口，让主图调整可在面板里完成，而不提前引入画布选择 / 自由变换系统。

对应手册 [11 裁剪](../../../docs/product/handbook/04-modules-core.md) 与 [11b 旋转与修改尺寸](../../../docs/product/handbook/04-modules-core.md)；壳层入口见 [docs/editor/shell.md](../../../docs/editor/shell.md)。`feature_list.json` 里相关项是 **feat-010**（矩形裁剪）、**feat-032**（修改尺寸），以及原 **feat-008** 中「调整面板旋转」子集。三项同属调整工作区、共用手风琴与主图文档字段，因此在本 change 一次交付一期切片；**feat-008 画布选择 / 移动 / 缩放 / 手柄旋转保持 not-started**。

## What Changes

- 【调整】面板改为三个一级入口：**裁剪**、**旋转/矫正**、**改尺寸/比例**；默认全部收起；同一时间只展开一个
- 点击入口展开对应功能界面；再点同一入口收起；展开另一入口时先收起当前项
- 用户在当前入口内做过操作后，收起或切换入口时，已生效的预览**提交到主图并保留**；未改动则主图不变
- **裁剪（一期）**：只做按比例裁剪（原比例 / 1:1 / 4:3 / 3:4 / 16:9 / 9:16 / 3:2 / 2:3）；画布 overlay 显示裁剪框与**仅限 host 内**的框外遮罩；框可拖动；四角与上下左右边中点按比例缩放；拖动时显示井字三分线、松开隐藏；应用后视口适配裁切结果并居中；确认后非破坏写入 `ImageLayer.crop`
- **旋转**：左旋 90°、右旋 90°、左右翻转、上下翻转、自定义角度；角度归一化到 0°～360°；翻转与旋转解耦；旋转 / 翻转后视口按包围盒实时适配并居中；收起后再进裁剪须按旋转后主图重算框的屏幕位置
- **改尺寸（一期）**：宽 / 高输入 + 锁定比例（默认开）+ 单位 px / in / cm；内部以 px 为真源；切换单位不改变实际尺寸；改的是主图显示尺寸，不是画布 / 文档尺寸
- 平移工具仍可用；无主图时入口可点开，但操作不改文档
- 三个操作走统一 Command 形状（execute / undo / redo）；本期接入最小命令栈，顶栏撤销 / 重做对本栈生效。完整历史（导入替换、滤镜、文字等）仍属 feat-014

## Capabilities

### New Capabilities

- `image-adjust`: 【调整】一期对主图的比例裁剪、旋转/翻转、改显示尺寸，以及手风琴提交/取消与最小命令栈

### Modified Capabilities

- `editor-shell`: 【调整】邻接面板从「平移 + 选择/裁剪/文字/形状占位」改为「平移 + 三个可展开调整模块」；切 Tab 不重挂 host 的约束不变

## Non-goals

- 不做主图自由选择、拖动、缩放、包围盒、Resize / Rotation Handle（feat-008）
- 不做按尺寸裁剪、按形状裁剪、圆形/多边形/蒙版裁剪、自定义尺寸预设列表
- 不做矫正 Tab、全图显示、自动裁剪、拉伸/AI 扩图/纯色背景、画质修复
- 不做多图层、多选、画布/文档尺寸调整、破坏性重采样、像素级烘焙原图
- 不实现 feat-014 全量命令覆盖（仅本三项操作的最小栈）
- 不为 Pixi WebGL 帧写 unit spec

## Impact

- UI：`EditorWorkspaceNav` 的调整面板替换 `EditorToolRail` 占位按钮；新增手风琴与 Crop / Rotate / Resize 子面板；平移入口保留
- 模型：扩展 `ImageLayer`（`crop`、`flipX` / `flipY`）；新增比例裁剪、角度、单位换算、锁比例纯函数；最小 Command 栈
- Pinia：主图仍是 `layers[0]`；新增更新 crop / transform / flip / 显示尺寸的 action；不新建第二文档 store
- 场景：`syncImageLayers` 按文档写 Sprite 变换、翻转与 crop mask；裁剪框画在已有 `overlay`，不进导出
- 工具：裁剪框拖拽 / 缩放手势只发 store action 或 Command，不直接改场景
- 无新 npm 依赖
- 验证：数学与 Command 用 vitest；裁剪框、遮罩、实时预览用手工验收
